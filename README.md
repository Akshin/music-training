# Тренировки

Набор музыкальных тренировок для музыкантов — на любом инструменте и голосом. Каждая
тренировка — своя страница с двумя экранами: описание (`/issue`) и сам прогон (`/resolve`).
Первая тренировка — тетрахорды.

Звук считает движок `src/audio-core/` (захват → анализ → скоринг → синтез). `/lab` — песочница:
компоненты интерфейса на живых данных с микрофона, без моков.

## Тетрахорды

- `/tetrachord-training/issue` — как устроена тренировка.
- `/tetrachord-training/resolve` — прогон.

### Как тренироваться

1. Открой **Тренировку**. Слева **Сейчас**, справа следующий лад и секунды до смены.
2. Задай темп и размер такта, нажми Play.
3. Играй или пой левую карточку от тоники: зелёный — тон (два полутона), жёлтый — полутон, серый ТС — тон между схемами. Над карточкой — пара схем (S1 + S3).
4. Когда правая карточка переезжает налево — это уже **Сейчас**. Не останавливайся.
5. Смену можно разредить: раз в такт или раз в несколько тактов. Таймер справа считает секунды до этой смены (темп, размер, сколько тактов).
6. Если схема не складывается с ходу — включи подсказку: табы гитары (первая позиция, лады 1–4) или клавиши пианино.
7. Чтобы слышать лад, в блоке **Звук** выбери тональный центр и включи «Мелодию» (гамма текущей карточки вверх и вниз) или «Бэк-трек» (струнная педаль). Подсказки рисуются от того же тонального центра.

Схему играют и вверх, и вниз: нисходящий ход — это та же схема задом наперёд.

### Что на карточке

Тетрахорд — четыре ступени в пределах чистой кварты. В тренировке их три вида:

1. **S1** · тон — тон — полутон
2. **S2** · тон — полутон — тон
3. **S3** · полутон — тон — тон

Лад = нижняя схема + **ТС** (тон связующий) + верхняя схема. Восемь нот, октава.

| Интервал      | Цвет    |
| ------------- | ------- |
| Тон           | зелёный |
| Полутон       | жёлтый  |
| Тон связующий | серый   |

Если пара схем совпадает с диатоническим ладом, под карточкой появляется имя:

- Ионийский · натуральный мажор — ТТП + ТС + ТТП
- Дорийский — ТПТ + ТС + ТПТ
- Фригийский — ПТТ + ТС + ПТТ
- Миксолидийский — ТТП + ТС + ТПТ
- Эолийский · натуральный минор — ТПТ + ТС + ПТТ

Остальные комбинации безымянные — их тоже играют. Лидийский и локрийский в случайной выдаче не появляются: им нужна схема тон–тон–тон.

### Экран тренировки

- **Ритм** — темп и размер такта: из них складывается пульс, по которому уезжает карточка; «Метроном» включает и выключает щелчки.
- **Упражнение** — как часто менять лад; подсказки Нет / Гитара / Пианино; «Отображение лада».
- **Звук** — тональный центр (12 тональностей); «Мелодия»; «Бэк-трек».
- Play внизу. Настройки прячутся крестиком, Play остаётся.

## Нота на долю

- `/note-on-beat/issue` — как устроена тренировка.
- `/note-on-beat/resolve` — прогон.

Циклы по два такта: в первом звучит нота, во втором её нужно спеть с сильной доли и держать две
доли. Ноты — из мажорной гаммы тонального центра, октава не важна. Микрофон слушает высоту и
время вступления; после каждой попытки видно отклонение в центах и миллисекундах, точки внизу —
история попыток. Лучше в наушниках.

## Запуск

```sh
npm install --legacy-peer-deps
npm run dev
```

Сборка: `npm run build`. Линт: `npm run lint`. Тесты движка: `npm run test:core`. Тесты логики
приложения (`src/training/__tests__`): `npm run test:app`.
