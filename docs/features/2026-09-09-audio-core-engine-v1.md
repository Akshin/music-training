# Звуковой движок audio-core v1 (M1–M7)

Дата: 2026-09-09 (коммит `24714ca`, "audio-core")

Платформонезависимый движок захвата, анализа, синтеза и скоринга звука для
тренировки музыкантов (слух, голос, инструменты), изначально добавлен в корень репозитория (позже
перенесён в `src/audio-core`).

## Что вошло в v1

Цепочка: mic → capture worklet → analysis worker → PCM-tape/OPFS → `/lab`
(визуализация pitch/level/spectrum, сегментация нот по Mauch, классификация
жестов питча, экспорт WAV, метроном и референсные сигналы, скоринг,
vibrato/formants/LUFS, pYIN, CPP, Superflux онсеты, источники из файла и
потока).

## За рамками v1 (бэклог)

Аккорды, WASM-реализации DSP (по профилировщику), декодирование mp3 внутри
ядра.

Подробности слоёв, модели данных и ADR —
[`src/audio-core/docs/ARCHITECTURE.md`](../../src/audio-core/docs/ARCHITECTURE.md).
